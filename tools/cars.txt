# Cars the aa.ev.model package can be built for: one line per HMG Leafia Plus
# v1.0.5 patch set (Leafia's patches/cars and patches/<set>/manifest).
#
# <car> <Leafia GPM APK md5> <Leafia GPM odex md5 or -> <Leafia AA library md5> <name>
#
# The APK and library md5s are the results in Leafia's manifest, so a build
# refuses files pulled from anything else. The odex is made on the car by
# dexopt when Leafia installs; "-" means it is not known yet and is taken
# from the pulled file (tools/pull_car_files.sh), then checked on every car
# at install time like the others.
#
# A car is built when private/<car>/ holds its files (see docs/PORTING.md).
